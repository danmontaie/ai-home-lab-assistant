AI Home Lab Assistant (Sprint 1)
Overview

Built an interactive AI assistant using Python, Google Cloud Vertex AI, and the Google Gen AI SDK. This project demonstrates the fundamentals of building applications powered by Gemini.

Technologies
Python
Google Cloud Vertex AI
Gemini 2.5 Flash
Google Gen AI SDK
Application Default Credentials (ADC)

✅ Configured Google Cloud project and Vertex AI
✅ Authenticated using Application Default Credentials
✅ Built an interactive command-line AI assistant
✅ Connected to Gemini using the Google Gen AI SDK
✅ Implemented custom system prompts
✅ Measured AI response times
✅ Learned the client → model → prompt → response architecture
