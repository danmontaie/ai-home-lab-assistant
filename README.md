# 🤖 AI Home Lab Assistant

An enterprise AI engineering project built with Python, Google Cloud Vertex AI, and Gemini.

This repository documents my hands-on journey from building a simple AI assistant to developing enterprise AI capabilities such as Retrieval-Augmented Generation (RAG), tool calling, and agentic workflows. Rather than relying only on courses or certifications, I'm learning by designing, building, and documenting real AI applications.

---

# 🚀 Project Vision

Build an enterprise AI assistant while learning the technologies and architectural patterns used in modern AI applications.

This project evolves through multiple stages:

- ✅ AI Assistant Foundations
- 🚧 Enterprise Knowledge Assistant (RAG)
- 🔜 Tool Calling & AI Integration
- 🔜 Agentic Workflows
- 🔜 Enterprise AI Platform

Each stage builds on the previous one, creating a single application that grows in capability over time.

# 📈 Project Philosophy

This repository is intentionally built in public as a learning journey.

Rather than creating multiple disconnected AI demos, I'm evolving a single application by introducing one enterprise capability at a time. Each milestone documents not only what was built, but also the architectural concepts and engineering decisions behind it.

The objective is to demonstrate practical AI engineering skills through continuous iteration, thoughtful design, and hands-on experience with Google Cloud and modern generative AI technologies.
