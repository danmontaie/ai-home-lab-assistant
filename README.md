# 🤖 AI Home Lab Assistant

An interactive AI assistant built with **Python**, **Google Cloud Vertex AI**, and **Gemini**. This project is part of my hands-on journey into cloud-native AI development, with a focus on learning by building real applications.

---

## 🚀 Project Goals

- Learn Google Cloud Vertex AI
- Build applications using the Google Gen AI SDK
- Understand prompt engineering and AI application architecture
- Progress toward Retrieval-Augmented Generation (RAG) and AI agents
- Develop a portfolio demonstrating practical AI engineering skills
